# 8-Days Basic Robotics

This repository contains a collection of Arduino projects used during an eight‑day robotics workshop. Each folder holds a small example or exercise. Open the corresponding `.ino` file in the Arduino IDE to upload the sketch.

## Projects
- **analog_voltmeter** – read analog voltage and print it to the serial monitor.
- **bluetooth module car** – control a robot car via Bluetooth commands.
- **bulb_control_using_bluetooth** – toggle a relay or bulb using an HC‑05 module.
- **distance Calculation** – measure distance with an ultrasonic sensor.
- **led_blinking_bluetooth_5led** – blink multiple LEDs via Bluetooth.
- **ultrasonic_car** – obstacle‑avoiding car controlled by an ultrasonic sensor.
- **Slides** – PDF slides from the training sessions.

Additional standalone examples are provided in the repository root:
- `led toggel esp8266 locally.ino`
- `linefollowing.ino`
- `temp&Humidity_Display_locally_usingESP8266.ino`
