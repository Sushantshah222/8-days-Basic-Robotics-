# Bulb Control Using Bluetooth

This folder contains two sketches that demonstrate controlling a relay (or bulb) over Bluetooth.

## Files
- **Bluetooth-realy-trigger.ino** – uses commands `1` and `0` to turn the relay on or off.
- **Bulb control using bluetooth.ino** – uses characters `G`, `R`, `O`, and `F` to control an LED and a bulb.

Upload the desired sketch, pair your HC‑05 module with a phone, and send the appropriate command from a Bluetooth terminal app.
