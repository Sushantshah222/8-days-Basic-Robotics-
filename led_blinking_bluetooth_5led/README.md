# LED Blinking via Bluetooth

This sketch blinks five individual LEDs when certain characters are received over the Bluetooth serial connection.

| Command | LED Pin |
| ------- | ------- |
| `a` | 4 |
| `b` | 7 |
| `c` | 8 |
| `d` | 12 |
| `e` | 13 |

Send `s` to print "Stop" in the serial monitor.
